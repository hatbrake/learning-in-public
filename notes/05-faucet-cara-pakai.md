# Faucet: cara pakai yang bener & etika

## Inti
Faucet = keran token testnet gratis buat bayar gas saat testing. Tokennya tidak
bernilai — cuma alat kerja, bukan cuan.

## Cara pakai
1. Siapkan wallet address testnet (MetaMask + network testnet, mis. Sepolia)
2. Buka faucet RESMI — dari docs/website project, jangan dari iklan hasil search
3. Tempel address, selesaikan verifikasi (CAPTCHA / login sosial), klik request
4. Tunggu konfirmasi on-chain (~15–30 detik), cek di block explorer

## Etika (yang sering dilanggar)
- Minta secukupnya — jangan hoarding. Faucet punya rate limit & stok terbatas
- Hormati cooldown (umumnya 1x24 jam per address)
- Satu address satu orang — drain pakai banyak address = perilaku sybil
- Kalau satu faucet kosong, coba faucet resmi lain, jangan brute force

## Contoh faucet resmi
- Chainlink Sepolia: via faucets.chain.link (0.1 SepoliaETH per request)
- Avalanche: via Core (core.app/tools/testnet-faucet)
