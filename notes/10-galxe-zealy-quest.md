# Galxe & Zealy: main quest yang efisien

## Inti
Galxe & Zealy = platform quest-to-earn. Project bikin tugas (follow, retweet,
coba testnet), user kerjakan, dapat poin/kredensial on-chain. Banyak airdrop
memakai riwayat partisipasi ini sebagai salah satu input eligibility.

## Cara main yang efisien
1. **Filter quest tanpa gas** — jangan bakar fee buat quest receh
2. **Pilih project yang jelas**: ada tim, funding, dan token belum launch.
   Platform dibanjiri campaign low-effort dari project yang tidak akan TGE
3. **Konsisten > maraton**: skor/reputasi naik seiring aktivitas rutin
4. **Wallet khusus**: pisahkan wallet quest dari wallet simpan (hygiene)
5. **Catat yang dikerjakan**: quest apa, kapan, di project apa — berguna saat cek eligibility

## Realita
- Quest ≠ jaminan airdrop. Poin adalah TIKET LOTRE, bukan gaji
- Waspada quest yang minta seed phrase / private key — 100% scam
- Galxe tidak pernah minta password sosmed — cuma izin baca dasar
